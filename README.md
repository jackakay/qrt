# QRT C3 hackathon

Team workspace. One folder per problem, one person per problem.

## Layout

| Folder | Problem | Owner |
| --- | --- | --- |
| p1/ | | |
| p2/ | | |
| p3/ | | |
| p4/ | | |
| p5/ | bonus | |

Each folder holds: `problem.md` (the statement), `solve.py` (the submission), `score.py` (local scorer).

## Start

```
git clone https://github.com/jackakay/qrt.git
cd qrt
codex
```

Codex reads `AGENTS.md` for the working rules. `PROMPTS.md` has prompts to paste.

## Rules for the team

1. Get a valid answer submitted on every problem before improving any of them.
2. Pull before you start, commit and push small and often. Stay inside your own folder to avoid conflicts.
3. Never commit an API key. Keys stay in your shell, not in files.
4. This repository is public. Make it private in Settings if other teams should not see it.
