# Working rules for this hackathon

- Each problem lives in its own folder (p1, p2, ...). Work only inside the folder I name. Do not read files outside it.
- Step 1: read the problem statement and restate the input format, the output format and the scoring rule in five lines. Then stop and wait for my OK.
- Step 2: write the simplest solution that produces a VALID output for every input. Validity before quality.
- Step 3: write score.py that checks validity and computes the score exactly as the statement defines it.
- Step 4: improve the score with a time-boxed heuristic (greedy first, then local search). Report the score before and after each change. Revert any change that does not help.
- Python 3, standard library unless I say otherwise. Explicit loops, no list or generator comprehensions.
- Never run anything longer than 60 seconds without asking. Every search takes a time limit argument.
- Keep replies short: what changed, the new score, the next idea. No long explanations.
- Never write an API key or any secret into a file.
